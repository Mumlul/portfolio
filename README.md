## 📁 Структура проекта

```

│
├── projects/
│   └── index.html          ← Страница проектов
│

│   ├── index.html          ← Страница достижений

│   ├── index.html          ← Страница сертификатов

│

    └── *.pdf / *.jpg       ← Подтверждающие документы
```

---

## ➕ Как добавить достижение / сертификат / активность

1. Положите файл (PDF, JPG, PNG) в нужную папку: `achievements/`, `certificates/`, `citizen/`
2. Откройте соответствующий `index.html`
3. Скопируйте существующую карточку (`<div class="achievement-card">` и т.д.)
4. Заполните данные: название, год, описание
5. Укажите правильный путь к файлу в строке `<div class="...-file-slot">`

---

## 🔄 Как работает «Показать ещё»

- По умолчанию на каждой странице видны **первые 4** карточки
- Кнопка «Показать ещё» открывает **все** карточки сразу
- Кнопка «Скрыть» сворачивает список обратно
- Если карточек 4 или меньше — кнопка **не показывается**

---

## 📸 Добавление фото

Положите своё фото в корень проекта с именем `photo.jpg`.  
Оно автоматически появится на главной странице.

---

## 🚀 Запуск

Просто откройте `index.html` в браузере.  
Для GitHub Pages — залейте папку в репозиторий, включите Pages в настройках.
