## 📁 Структура проекта

```
portfolio/
├── index.html              ← Главная страница
├── style.css               ← Общие стили (все страницы)
├── script.js               ← Общий JS (все страницы)
├── photo.jpg               ← Ваше фото (добавьте сами)
│
├── projects/
│   └── index.html          ← Страница проектов
│
├── achievements/
│   ├── index.html          ← Страница достижений
│   └── *.pdf / *.jpg       ← Сюда кладите файлы наград
│
├── certificates/
│   ├── index.html          ← Страница сертификатов
│   └── *.pdf / *.jpg       ← Сюда кладите сертификаты
│
└── citizen/
    ├── index.html          ← Страница "Гражданин"
    └── *.pdf / *.jpg       ← Подтверждающие документы
```

## 🛠️ Технологии

- Чистый HTML / CSS / JavaScript (без фреймворков)
- Шрифты: Playfair Display, DM Sans, JetBrains Mono (Google Fonts)
- Анимации: CSS + IntersectionObserver
- Совместимость: все современные браузеры
